01 · pitch

frequency_by_crossings

Frequency from rising zero crossings. Counting whole crossings over a fixed window resolves only to one cycle, so the error grows as the tone gets lower. Interpolating the first and last crossing to sub-sample position removes that limit.

02 · aliasing

additive_saw, trivial_saw, alias_to_signal_db

additive_saw sums only the harmonics below Nyquist, so it has no aliasing by construction. trivial_saw samples the ramp directly, so most of its energy is alias. Run an analysis on both: what it reports for the additive saw is its own noise floor.

03 · exactly periodic analysis

periods_for

Given a target frequency, a rate and a buffer length, it returns a whole odd cycle count coprime with the length. A tone at that frequency lands on one bin, so no window function is needed and there is no window main lobe for a defect to hide under.

04 · system response

transfer_gain and Probe

Drives a closure with a sine, discards Probe::settle samples, and returns the peak of what is left. One call per frequency gives a magnitude response.

05 · tonality

spectral_flatness_db

Geometric mean of the magnitude spectrum over its arithmetic mean, in dB, across a bin range. Independent of level. Flat spectra approach 0; energy concentrated in peaks drives it down.

06 · audibility weighting

a_weight

The IEC 61672 A-weighting curve as a linear gain at one frequency. Applied per bin it turns a raw spectrum into a rough audibility ranking. It is not a masking model and should not be used as one.

07 · discontinuities

worst_step

Returns the largest absolute difference between neighbouring samples and its index. A click is a discontinuity, so this turns "does the transition click" into a number and a sample position.

08 · two contracts worth knowing

Endpoint bins, and rounding to i16

Two places where the obvious implementation is off by a fixed factor. Both are pinned by tests.

09 · contracts

What the crate will and will not do

Rulers, not verdicts

Named computations only. No thresholds, tolerances, margins, default epsilons or pass/fail helpers: those stay in the test that owns the decision.

Absence over zero

No pitch in silence, no flatness in an empty band, no peak in a buffer holding a NaN. Those return None, because 0.0 would pass a "below threshold" assertion.

Negative infinity is a value

amplitude_db(0.0) is -inf, not a floor. Buffer measurements never return NaN.

Two callers to enter

A computation moves in when two call sites compute the same quantity. Single-use helpers stay where they are used.

Deterministic input

noise is seeded and reproducible. Nothing here reads the clock or the environment.

Tests only

Every consumer depends on it under [dev-dependencies], so it is in no shipped plugin's graph. A check enforces that.

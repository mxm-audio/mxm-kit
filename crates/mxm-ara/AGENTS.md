Parent: [`../../AGENTS.md`](../../AGENTS.md). Why things are as they are: [`NOTES.md`](NOTES.md).

# Purpose

The plug-in side of ARA 2 (Celemony's Audio Random Access, SDK 2.3) in Rust, and a Rust ARA test
host. Written as stage 5 of newDAWn's `plans/plan-pitch-plugin.md`: mxm-fx-pitch's Studio mode
reads the host's takes and renders corrected regions through it. It knows nothing of pitch: a
plug-in implements `Controller`, and hands nice-plug's `AraHooks` `factory::<C>()` and `bind_into`.
Its second user is newDAWn's ARA host (newDAWn's `plans/plan-ara-host.md`), which adds the host's
half as `mxm_ara::hosting`: **one set of ARA bindings for the collection**.

# Ownership

- `ara_api/` — ARA_API 2.3's `ARAInterface.h`, vendored unchanged, with the SDK's licence and
  notice. Never edited; a new SDK replaces it whole, then `tools/gen-bindings.sh` runs.
- `src/sys.rs`, `src/sys/{x86_64,aarch64}.rs` — the raw bindings, generated by
  `tools/gen-bindings.sh` (bindgen 0.73.2) and checked in, so no build needs libclang. Never
  edited by hand.
- `src/` — the safe layer: `factory` (the static `ARAFactory`, init/uninit), `document` (the
  document controller's whole interface), `graph` (the model graph), `extension` (bound
  instances, roles, the render access), `host` (the host's interfaces: audio readers, content,
  archives, playback), `archive` (the container), `notify`, `guard`, `content`, `validate`.
- `src/test_host.rs` — the test host, behind the `test-host` feature.
- `src/hosting.rs` — the host's half, for newDAWn's ARA host (`plans/plan-ara-host.md`): a
  factory initialized and counted, the host's interfaces behind the `Host` trait, a document
  controller's whole interface, a bound instance's renderers and view.
- `tests/` — the integration tests, through the test host; `tests/common` is their controller.
- In mxm-kit since 2026-11-23, MIT (the owner: "yes, move mxm-ara to mxm-kit under MIT"), the
  vendored header and the generated bindings under Celemony's Apache 2.0 (`NOTICE.md`).

# Local Contracts

- **The C boundary is the only `unsafe`.** Every `unsafe` block carries a `SAFETY:` comment. A
  host struct is read field by field as far as its `structSize` goes (`read_field!`), never
  whole; our structs' `structSize` is `implemented_size!` up to the last field implemented,
  never `size_of`. Packed (x86) fields are copied out, never borrowed.
- **Never crash the host.** An invalid call is reported through the host's assert function and
  `api_violations()`, then refused or ignored. Every ref from the host is checked against the
  live objects before it is followed (except `getPlaybackRegionHeadAndTailTime`, below).
  Panics in a `Controller` hook are caught; the controller turns inert.
- **One model thread.** Every document controller call, extension call and hook runs on the
  thread that created the controller, one at a time (checked; re-entrance refused).
- **The graph changes only with renderers out.** Graph edits happen with the guard closed: for
  the whole of a host's edit, and around any change the host makes outside one. Renderers read
  only inside `render_access()`, which never waits, locks or allocates (held by
  `render_path_allocations`). A graph edit waits for renderers inside to leave.
- **Readers are joined before the host's call returns.** Disabling sample access, changing a
  source's format, destroying it (or the controller) cancels its readers, waits for a read under
  way, and destroys them on the model thread. Host readers are created and destroyed only in the
  calls ARA allows (`Cx` grants them by scope); a reader dropped on a worker is destroyed at the
  next such call.
- **Host calls only where ARA allows them.** Audio readers and host content (tempo, bars, key)
  through `Cx` in a call about that object or at the end of an edit; model update notifications
  queued from any thread but the audio thread and sent only from `notifyModelUpdates`; a
  notification about an object since destroyed is dropped.
- **Archives are the container's** (`src/archive.rs`): one entry per object, under its persistent
  ID, with the controller's schema. Filters and ID mapping as ARA_Library applies them. An entry
  of a newer schema than `Controller::ARCHIVE_SCHEMA`, and an entry of an unknown kind, is kept
  verbatim and written back unchanged. The container's version is frozen: new needs are new
  entry kinds.
- **Head and tail times from any thread.** `getPlaybackRegionHeadAndTailTime` reads only the
  region's cell (atomics, allocated apart from the region), never the graph or a lock, and trusts
  the region ref, as ARA's any-thread call has to.
- **API generations 2.0 final to 2.3** (`LOWEST_API_GENERATION`, `HIGHEST_API_GENERATION`). No
  ARA 1: the extension's ARA 1 interface is null; the deprecated restore and store calls map to
  their successors, as ARA_Library maps them.
- **The host's half keeps the same boundary** (`hosting`):
  - **Sizes:** the host's tables advertise the host's own size; a plug-in's are read as far as
    their `structSize` goes, zero past it, and refused below their `…MinSize`.
  - **Generations:** 2.3 when the factory offers it, else the highest from 2.0 final up
    (`LOWEST_HOSTED_GENERATION`, `HIGHEST_HOSTED_GENERATION`).
  - **Initialization:** once per factory per process, however many hold it; the last
    `Initialized` dropped uninitializes.
  - **Threads:** a document controller's calls are refused off the thread that made it; a call
    the plug-in lacks is `None`. Archives are bytes handed in and out per call.
  - **Never wait in a read:** a `Host`'s reads never wait on the controller's thread or a render
    thread.
- **Either teardown order.** A `PlugInExtension` may be dropped before or after the controller is
  destroyed; after it, `render_access()` and `with_controller` give `None`.

# Work Guidance

- Use it from a plug-in: `impl Controller for StudioController` (its `FACTORY.plug_in_name` equal
  to the plug-in's VST3 class name and CLAP name); `AraHooks { factory: || factory::<StudioController>().cast(),
  bind: |p, dc, known, assigned| bind_into(&mut p.ara, dc, known, assigned), .. }`; in
  `process()`, `if let Some(access) = p.ara.as_ref().and_then(|a| a.render_access())`, else
  silence.
- What the audio thread reads that a worker changes (a finished render) lives in the region's
  data behind an atomic swap; what an edit changes, the graph holds.
- What an instance's editor renderer was given (its regions and region sequences) is
  `Cx::editor_renderer(extension)`, in any hook: mxm-fx-pitch finds there the editor in charge
  of a hidden playback renderer's region (REAPER's way of binding).
- A new ARA SDK: replace `ara_api/` whole, run `tools/gen-bindings.sh`, review the diff of
  `src/sys/`, then extend `implemented_size!` targets to any new field implemented.
- Tests drive the controller only through the C tables (`test_host`), never through internals;
  each test that measures something carries a control that fails it.

# Verification

```bash
# From the repository (Linux's cargo wrapper builds below MXM_BUILD_ROOT).
cargo fmt --all -- --check
cargo clippy -p mxm-ara --all-targets -- -D warnings
cargo test -p mxm-ara
sh tools/gen-bindings.sh && git diff --exit-code src/sys   # the bindings regenerate unchanged
```

| Test file | Holds |
|---|---|
| `tests/factory.rs` | The factory's fields and size; generations 2.0 final to 2.3 accepted, older refused and reported |
| `tests/model_graph.rs` | The graph through create, update and destroy; invalid calls refused; roles and binding once; renderer lists, what an editor renderer was given as the controller sees it, and the view's selection; the song key read only where allowed; content offered to the host |
| `tests/audio_reader.rs` | The right samples on a worker in f32 and f64; a read under way joined before disabling or destroying returns; progress notifications in order |
| `tests/archive.rs` | Round trip; filtered store and restore with IDs mapped; a newer schema kept and written back byte for byte; a malformed object; a cloned modification |
| `tests/teardown.rs` | Both teardown orders |
| `tests/renderer_guard.rs` | Refused at once during an edit; an edit waits for a renderer; never half an edit |
| `tests/render_path_allocations.rs` | The render path neither allocates nor frees |
| `tests/struct_sizes.rs` | An older host's smaller structs read and called only as far as they go |
| `tests/hosting.rs` | The host's half driving the plug-in side: a document built, read on the plug-in's worker, stored and restored into another; a bound instance's regions and selection in either teardown order; calls off the controller's thread refused; one initialization however many hold it; a plug-in's tables read only as far as they go, generations negotiated; no assert and no violation |

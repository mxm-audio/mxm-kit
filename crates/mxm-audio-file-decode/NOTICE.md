Third-party software: Symphonia

This software contains the following crates of Symphonia, a pure Rust audio decoding and media
demuxing library, version 0.6.1, used unmodified:

  symphonia, symphonia-core, symphonia-common, symphonia-metadata,
  symphonia-format-riff, symphonia-format-isomp4, symphonia-format-ogg,
  symphonia-bundle-flac, symphonia-bundle-mp3,
  symphonia-codec-pcm, symphonia-codec-alac, symphonia-codec-aac, symphonia-codec-vorbis

They are licensed under the Mozilla Public License, version 2.0 (MPL-2.0). A copy of the licence is
available at https://mozilla.org/MPL/2.0/.

Their source code is available, free of charge:

  https://github.com/pdeljanov/Symphonia   (release v0.6.1)
  https://crates.io/crates/symphonia/0.6.1  (and each crate named above, at version 0.6.1)
